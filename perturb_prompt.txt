============================================================
1. METHOD TO IMPLEMENT
============================================================

Working name:

Conditional Feature Freedom (CFF)

The method is a class-conditional, data-driven perturbability proxy.

For each candidate feature Xi, estimate how predictable Xi is from all of the other features X_-i within the SAME traffic/attack class.

The reasoning is:

If Xi is almost completely predictable from the remaining features, then Xi is likely:

- derived,
- tightly constrained by feature relationships,
- redundant,
- near-constant,
- or structurally unsuitable for independent perturbation.

If Xi retains substantial residual variation after conditioning on all other features, then it has greater conditional freedom and becomes a stronger candidate for perturbation.

This does NOT prove physical packet-level controllability.

CFF should therefore be described as:

    a data-driven proxy for ranking candidate perturbable features

or:

    a measure of class-conditional feature freedom.

Conceptually, the method estimates:

    Var(X_i | X_-i, class=c)

using nonlinear out-of-fold regression residuals.

============================================================
2. MATHEMATICAL DEFINITION
============================================================

For each attack class c and candidate feature i:

Train a nonlinear predictor:

    X_hat_i = f_i(X_-i)

where:

- X_i is the target feature.
- X_-i contains every other eligible modelling feature.
- Data comes ONLY from class c.
- Predictions MUST be out-of-fold.
- The attack/class label must NEVER be included in X_-i.

For every out-of-fold sample:

    r_i = X_i - X_hat_i

Compute robust residual spread:

    residual_span_i =
        Q95(r_i) - Q05(r_i)

Compute the feature's robust natural spread:

    feature_span_i =
        Q95(X_i) - Q05(X_i)

Define:

    CFF_raw_i =
        residual_span_i /
        (feature_span_i + epsilon)

and:

    CFF_i =
        clip(CFF_raw_i, 0, 1)

Interpretation:

    CFF approximately 0:
        feature is highly predictable from the other
        features and therefore appears structurally
        constrained or derived.

    CFF approximately 1:
        substantial variation remains after conditioning
        on all other features, indicating greater observed
        conditional freedom.

CFF is a relative statistical ranking.

It must NOT be described as proof that the feature is physically mutable.

10. OUT-OF-FOLD PREDICTION
============================================================

Never fit and evaluate Xi on the same rows.

Use out-of-fold prediction.

Default:

    KFold(
        n_splits=3,
        shuffle=True,
        random_state=42
    )

Preferred implementation:

Explicit fold loop rather than blindly using cross_val_predict.

Pseudo-logic:

    oof_pred = np.empty(len(X))

    for train_idx, val_idx in kfold.split(X):
        model = make_lgbm_model(...)
        model.fit(
            X_train_fold,
            y_train_fold
        )

        oof_pred[val_idx] = model.predict(
            X_val_fold
        )

This gives exact control over LightGBM and avoids accidental nested parallelism.

Do not use the NIDS validation set here.

The "validation" fold above is only an internal fold drawn from TRAINING DATA.

29. SCIENTIFIC INTERPRETATION
============================================================

Put a clear explanation in the module docstring.

CFF estimates:

    how much feature Xi varies after conditioning on
    all other features within the same traffic class.

Operational approximation:

    X_hat_i =
        LightGBM(X_-i)

    residual_i =
        X_i - X_hat_i

The normalized robust residual spread becomes CFF.

The rationale:

A feature that is highly predictable from the remaining flow attributes likely participates strongly in structural, derived, or otherwise constrained relationships.

A feature exhibiting substantial out-of-sample residual variation has greater observed conditional freedom and is therefore a stronger candidate for adversarial perturbation.

CFF does NOT prove:

- attacker accessibility,
- packet-level mutability,
- functionality preservation,
- causal controllability.

Those require separate problem-space validation.

30. EQUATIONS TO DOCUMENT
============================================================

For attack class c:

    X_hat_i = f_i(X_-i)

where f_i is LightGBM regression.

Out-of-fold residual:

    r_i = X_i - X_hat_i

Robust residual width:

    W_r(i) =
        Q_0.95(r_i) - Q_0.05(r_i)

Feature width:

    W_x(i) =
        Q_0.95(X_i) - Q_0.05(X_i)

Conditional Feature Freedom:

    CFF_i =
        clip(
            W_r(i) /
            (W_x(i) + epsilon),
            0,
            1
        )

Higher CFF:

    greater observed conditional freedom

Lower CFF:

    greater conditional predictability / structural constraint.
